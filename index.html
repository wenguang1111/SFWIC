按键指南

A / D 或 ← / →
左右移动；地面按住远离对手的方向可站防。
S 或 ↓
下蹲；同时按住后方向为蹲防。站防挡上段与中段，蹲防挡中段与低段。
W 或 ↑
跳跃，配合方向斜跳；落地时仍按住会再跳。
J / K / U / I
A 轻拳 / B 轻脚 / C 重拳 / D 重脚。站、蹲、跳各有四种普通技。
J + K
同时按下（3 帧内先后也算），角色专属防守技，有冷却。
近身 ←/→ + U
普通投，无视防御。
↓↘→ + J/U
指令技按角色面朝右记，换边自动镜像。招式表写成 ↓↘→ + 拳(J/U)，即依次按 ↓、↘、→ 后按 J 或 U；「拳」= J 或 U，「脚」= K 或 I。
←(蓄) →
蓄力技：按住后方向约 0.7 秒再推前方向并出招；蓄力期间照样能防御。
连招
轻攻击可以互相连打；轻攻击与近身重攻击命中或被防的瞬间输入必杀技即可取消接上。场地上方显示 HITS 与连段伤害。
超必杀
能量条过 50 的刻线即可用，如 ↓↘→↓↘→ + 拳，起手画面暗场。
练习模式
开局前在目标下方勾选：不计时，陪练站着不动，可选站防或蹲防。
Esc
暂停或继续。切换窗口会自动暂停。
