# 连招与指令体系设计

## 1. 参考：拳皇 '97 的连招是怎么构成的

拳皇 '97 的爽快感主要来自四个机制叠在一起，不是某一招本身：

| 机制 | 作用 | 本作对应 |
|---|---|---|
| **四键**：A 轻拳 / B 轻脚 / C 重拳 / D 重脚 | 拳脚分工明确，近身重击与远身重击有别 | J=A，K=B，U=C，I=D |
| **方向指令**：↓↘→、→↓↘、↓↙← 等，以数字键盘方向记作 236、623、214 | 必杀技靠"搓"出来，有输入门槛和成就感 | 指令按角色朝向解释，换边自动镜像 |
| **取消（Cancel）**：普通技命中或被防的瞬间接必杀技 | 让"轻 → 重 → 必杀"真正连上，而不是三次独立出招 | 招式标注可取消的去向和时间窗 |
| **硬直差**：受击硬直比攻击收招长才连得上；命中停顿（hitstop）让每一击有分量 | 连招成立与手感的底层 | 每招独立配置 hitstun / blockstun，命中时双方冻结数帧 |

拳皇 '97 里不同角色的连招"味道"来自他们必杀技的**结构类型**，而不是按键多少。整理下来可以归纳成以下几类：

| 连招类型 | 结构 | 拳皇 '97 中的代表 | 玩家感受 |
|---|---|---|---|
| **派生连段（Rekka）** | 同一指令连续输入 2–3 次，每段都可停 | 八神庵「葵花」三段；草薙京「荒咬み → 九傷 → 七瀬」 | 节奏感强，可在任意一段收手骗对手 |
| **升龙对空（DP）** | 623 + 键，起手无敌的上升攻击 | 京、庵的「鬼焼き」；坂崎良「虎砲」 | 读对手跳入，一击反制 |
| **蓄力技（Charge）** | 先按住后 / 下约 0.7 秒，再推反方向 + 键 | 特瑞「Rising Tackle」；金家藩「飛燕斬」 | 后退蓄力，节奏防守反击 |
| **飞行道具（Zoner）** | 向前发出持续存在的攻击体 | 特瑞「Power Wave」；雅典娜「Psycho Ball」；庵「闇払い」 | 远距离压制，逼对手跳 |
| **指令投（Grappler）** | 半圈 / 整圈 + 键，近身无视防御 | 大门五郎「天地返し」等；克拉克、夏尔米 | 对手不敢一直防，形成"打与投"二择 |
| **腿技连踢 / 旋转（Kick rush）** | 多段腿技或带位移的旋转踢 | 金家藩「鳳凰脚」；二阶堂红丸带旋转的雷电技 | 华丽、多段、命中数多 |
| **突进（Rush）** | 带位移的单发突击，适合远距离插入 | 不知火舞「必殺忍蜂」；红丸「居合い蹴り」 | 突然拉近距离 |
| **当身 / 反弹（Counter）** | 架势期间接住攻击并反击 | 山崎龙二「倍返し」反弹飞行道具 | 读招，惩罚冲动的对手 |

超必杀技（Desperation Move）通常是 236236 或 214214 一类双圈指令 + 键，消耗能量，既是连招终结也是逆转手段。

> 本作只借鉴这些**机制与结构**，不使用拳皇或街霸的代码、图像、音效、角色或招式名。网上能找到的"原代码"并不存在官方公开版本：MAME 是运行原版 ROM 的模拟器，ROM 本身受版权保护；开源的 Ikemen GO（MIT 许可）是兼容 MUGEN 素材的桌面引擎，可以参考它的设计，但它不是拳皇源码，而网上流传的 MUGEN 拳皇角色大多是未经授权的翻录素材，不能用于本项目。

## 2. 本作的连招类型库

连招类型做成**可复用的招式模板**（`src/moves/archetypes.js` 中的工厂函数）。新角色只需要挑选模板、填数值和美术，不需要改引擎。

| 模板 | 指令惯例 | 规则要点 |
|---|---|---|
| `rekka` 派生连段 | 236 + 拳，连续输入 2–3 次 | 每段命中或被防后的时间窗内可接下一段；最后一段击倒 |
| `risingAntiAir` 升空对空 | 623 + 键 | 起手若干帧对打击无敌；上方判定，适合打跳入 |
| `chargeProjectile` / `chargeRise` 蓄力 | [4]6 / [2]8 + 键 | 后 / 下蓄满约 40 帧；蓄力期间可正常防御 |
| `projectile` 飞行道具 | 236 + 拳 | 生成独立攻击体，双方飞行道具相撞抵消 |
| `commandThrow` 指令投 | 41236 + 拳 | 近身、无视防御；被跳或打断即失败，空振收招长 |
| `spinRush` 旋转连踢 | 214 + 脚 | 多段命中、带位移；适合作为连招终结 |
| `rushStrike` 突进 | 236 / 214 + 键 | 单段、长位移 |
| `groundWave` 地波 | 236 + 脚 | 贴地低段攻击体，可跳过 |
| `superMove` 超必杀 | 236236 + 键，消耗 50 能量 | 多段；起手画面暗场，起手几帧无敌 |

所有角色共享：站 / 蹲 / 跳 × A B C D 普通技、近身 ←/→ + C 普通投、A+B 角色专属防守技。轻攻击可以互相连打（链），轻攻击和近身重攻击可以取消接必杀与超必杀。

## 3. 角色分配

| 角色 | 主连招类型 | 招式 | 代表连招 |
|---|---|---|---|
| **烬** 疾攻 | 派生连段 + 升龙 | 炎牙三段 236P×3；升炎 623P；赤焰冲 214K；踏火 6B；超必杀 焚天 236236P | 近 C → 炎牙 → 炎牙·贰 → 炎牙·叁 |
| **澜** 牵制 | 蓄力 + 飞行道具 + 当身 | 潮弹 [4]6P；潮升 [2]8K；落潮掌 6C（中段破蹲防）；回流（A+B 当身）；超必杀 怒涛 236236P | 2B → 2B → 潮弹；对空用潮升 |
| **岳** 重压 | 指令投 + 地波 | 山崩摔 41236P；地鸣 236K；磐石进 214P（可硬吃一击）；超必杀 天地返 236236C | 2B → 地鸣；或贴身逼防御后山崩摔 |
| **冰上少女** 滑步 | 旋转连踢 + 突进 | 旋风连转 214K（三段旋转踢）；阿克塞尔 623K（升空旋转踢对空）；冰弧突进 236P；蹲 D 蹲转扫；超必杀 三周半·终曲 236236K | 跳 D → 站 D → 旋风连转；对空阿克塞尔 |

花滑的特色放在**旋转**：她的必杀技全部是旋转腿或滑行，对应花滑的旋转（spin）与阿克塞尔跳（axel）。冰刀只作为脚下的滑行工具，不作为砍人的武器。

## 4. 指令记法

数字对应键盘小键盘方向，以**角色面朝右**为准，面朝左时自动镜像：

```
7 8 9      ↖ ↑ ↗
4 5 6  =   ← · →
1 2 3      ↙ ↓ ↘
```

`236` = ↓↘→，`623` = →↓↘，`214` = ↓↙←，`41236` = ←↙↓↘→，`[4]6` = 按住 ← 蓄力后推 →，`P` = A 或 C，`K` = B 或 D。
